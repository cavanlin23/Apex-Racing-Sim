# APEX — Racing Sim

Browser racing, drifting and free-roam game (three.js).

- Race and Practice on six circuits: Spa, Shanghai, Nürburgring GP, Bahrain, Yas Marina, Marina Bay
- Free drive open world with a stunt park, Drift arena with ramps and tricks
- 19 full-detail car models, manual gearbox and manual brakes

## Play
Needs a web server (browsers block loading models from `file://`):

    python3 -m http.server 8000     # then open http://localhost:8000

or host free on GitHub Pages: repo → Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
Needs internet for the three.js library (cdnjs / jsDelivr).
